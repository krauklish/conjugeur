# Conjugeur

A small French conjugation trainer: mobile-first, web-based, works offline once loaded.
The user sees a sentence with a blank, works out which verb form the context requires, and types it.

## Running

No build step and no runtime dependencies. Node is used only for tests and data checks.

```bash
npm start                              # serve the app at http://localhost:5173
npm test
npm run validate
npm run sw                             # REQUIRED after changing css/, js/, icons/, index.html or the manifest
npm run icons                          # regenerate the icons (then run `npm run sw`)
npm run sentences -- --verb aller      # print generated sentences for proofreading
npm run sentences -- --count           # totals per verb × form
```

## Layout

```
js/data/     forms.js (form registry), verbs.js (conjugation tables),
             subjects.js, frames.js, complements.js (sentence content)
js/core/     conjugator.js, french.js (elision, agreement, normalisation),
             generator.js (frame + subject + verb form + complement → exercise),
             checker.js (typed answer → verdict and diagnosis),
             scheduler.js (weighted choice of the next verb × form, statistics),
             store.js (localStorage: selection and statistics)
js/ui/       practice.js, settings.js, progress.js, strings.js (all French UI text), dom.js
js/main.js   bootstrap, view registry, navigation
js/sw-register.js   service worker registration and update notice
index.html, css/app.css, sw.js, manifest.webmanifest, icons/
prototype/   index.html: single-file design prototype with mocked data (not the app)
tests/       node:test suites
tools/       validate-data.mjs, validate-sentences.mjs, dump-sentences.mjs,
             build-sw.mjs (precache list and version), make-icons.mjs
```

## Offline

`sw.js` precaches the whole app and serves it cache-first. Its file list and version hash are
generated by `npm run sw`; `npm test` fails if they are stale, so run it before committing any
change to shipped files. On localhost the worker is registered only with `?sw=1` in the URL, so
development is not served from cache; unregister it afterwards in DevTools.

## Sentence content

A sentence is `frame + subject + verb form + complement`, combined mechanically, so each piece
must be safe to combine. Combinations that don't work are switched off with:

- frame: `notVerbs`, `notPersons`, `notSubjects`
- complement: `notForms`, `notFrames`, and `aux` (auxiliary override, used by `passer`)

Rules for new content: B1 vocabulary; a frame must force its form (no other of the trained forms
equally correct); complements carry no time expression, nothing that depends on the subject, no
negation. After adding a verb or frame, run `npm run validate` and read `npm run sentences -- --verb <inf>`.

## Decision log

| Date | Decision | Why |
|---|---|---|
| 2026-11-22 | Vanilla HTML/CSS/JS with ES modules; no framework, no build step, zero runtime dependencies | Requirement: as few libraries as possible |
| 2026-11-22 | Offline via service worker precache plus web manifest; state in `localStorage` | App and data are a few dozen KB; no server needed |
| 2026-11-22 | Tests use Node's built-in `node:test` | No test dependency |
| 2026-11-22 | Sentence = frame + subject + verb form + complement, each a separate data layer | Adding verbs or forms later must not touch code |
| 2026-11-22 | Simple tenses stored as explicit tables; compound tenses derived from auxiliary + participle | The top 20 verbs are nearly all irregular; a rule engine would be mostly exceptions |
| 2026-11-22 | Data lives in JS modules, not JSON | Synchronous imports, same files usable from Node tests |
| 2026-11-22 | Verb list v1: être, avoir, faire, dire, pouvoir, aller, voir, savoir, vouloir, venir, devoir, prendre, trouver, donner, falloir, parler, mettre, passer, croire, aimer | 20 most used; `falloir` kept although impersonal (tables allow `null`) |
| 2026-11-22 | Forms v1: indicatif présent, passé composé, imparfait, futur simple; subjonctif présent, passé | Set by the owner |
| 2026-11-22 | The form name is hidden until the answer is checked | Deducing the form is the exercise |
| 2026-11-22 | A missing or wrong accent counts as wrong, but is reported as "accent only" | Goal includes writing the form correctly |
| 2026-11-22 | Where participle gender or number is unknown (je, tu, nous, vous, on), all agreeing variants are accepted | The sentence gives no way to decide |
| 2026-11-22 | A person is treated as missing for a verb when no simple tense has a form for it (drives `null` for falloir's compound forms) | Derived from the data, no special-casing of `impersonal` in code |
| 2026-11-22 | `passer` defaults to auxiliary avoir; sentences can override per complement (`opts.aux`) | Its auxiliary depends on meaning |
| 2026-11-22 | Sentence vocabulary and structures are CEFR B1 | Owner's choice |
| 2026-11-22 | Complements live in `complements.js` keyed by infinitive, not inside `verbs.js` | Keeps the verified conjugation tables separate from editorial content |
| 2026-11-22 | Bad combinations are excluded explicitly (`notVerbs`, `notPersons`, `notSubjects`, `notForms`, `notFrames`), with named groups for readability | Simple and reviewable at 20 verbs. If the verb list grows a lot, consider tags (frame `needs`, complement `avoids`) so a new verb doesn't require touching frames |
| 2026-11-22 | Passé composé frames with only a past time point (hier soir…) exclude stative and modal verbs; those verbs get bounded-duration frames (« pendant deux ans ») | With a bare time point the imparfait is equally correct for être, pouvoir, vouloir, devoir, falloir |
| 2026-11-22 | Futur frames avoid markers where the présent is as natural (« l'année prochaine », « plus tard ») | The learner must not be marked wrong for a correct alternative |
| 2026-11-22 | Subjonctif passé frames always carry a past marker after the complement; subjonctif présent frames with a non-volitional trigger carry a present or future marker | Keeps the two subjunctive forms from being interchangeable |
| 2026-11-22 | Invariant: every verb × form keeps at least 3 usable frames and 3 usable complements (validator warns below 3 frames) | Enough variety without forcing unnatural sentences |
| 2026-11-22 | Visual design: black on white, one accent colour (#1440ff), system sans, three type styles, no icons, images or shadows | Owner's brief; see `prototype/index.html` |
| 2026-11-22 | No on-screen accent keys | Owner's decision; the phone keyboard is enough |
| 2026-11-22 | One persistent input that never loses focus; Enter checks, Enter again continues | Keeps the phone keyboard open and the flow keyboard-only |
| 2026-11-22 | Checker diagnoses wrong answers (other form, other person, agreement, auxiliary); an exact match of another form wins over an accent-only slip | More useful feedback than a bare "wrong" |
| 2026-11-22 | Views are registered in `main.js` (`{ id, label, mount }`) and share a `ctx` (selection, score) | Settings and progress screens plug in without touching the practice view |
| 2026-11-22 | Progress is tracked per verb × form (`seen`, `right`, `streak`), not per person or per sentence | Small, readable statistics; enough to steer practice |
| 2026-11-22 | Next pair is a weighted random choice: weight = 1 + 4 × (1 − smoothed accuracy), halved after 3 correct in a row; never the same pair twice running | Weak and unseen pairs come up more often, mastered ones still return |
| 2026-11-22 | An accent-only slip counts as not right in statistics and score | Consistent with "accents matter" |
| 2026-11-22 | Storage keeps what is switched OFF, under one key `conjugeur.v1` | Verbs and forms added later are on by default |
| 2026-11-22 | Storage never throws; falls back to memory when unavailable | Private mode and blocked storage must not break practice |
| 2026-11-22 | Service worker version is a content hash written by `npm run sw`, guarded by a test | No build step, yet a forgotten version bump cannot go unnoticed |
| 2026-11-22 | A new version waits; the page shows « Nouvelle version disponible » and updates only when the user asks | Never reload in the middle of an exercise |
| 2026-11-22 | No service worker on localhost unless `?sw=1` | Cache-first would hide edits during development |
| 2026-11-22 | Icons are generated by a dependency-free script: white square, black bar, accent caret | Matches the app's design; no image assets to maintain |
| 2026-11-22 | UI language is French | Owner's choice |
| 2026-11-22 | Hosting: GitHub Pages | Static HTTPS is all a service worker needs |
